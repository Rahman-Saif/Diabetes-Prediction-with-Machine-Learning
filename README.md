## 📖 Overview
This project is a Machine Learning-based diabetes prediction system developed using Python. The main goal of the project is to predict whether a person is diabetic or not based on several medical attributes.

The project follows a complete ML workflow including:
- Data preprocessing
- Log transformation
- Feature scaling
- Model training using SVM
- Prediction

## ⚙️ Machine Learning Workflow

### 1️⃣ Data Preprocessing
- Checked missing values
- Cleaned and prepared dataset
- Feature selection

### 2️⃣ Log Transformation
Applied log transformation on skewed features to improve data distribution and model performance.

### 3️⃣ Feature Scaling
Used scaling techniques to normalize feature values before training the model.

### 4️⃣ Model Training
Used **Support Vector Machine (SVM)** for classification.

### 5️⃣ Prediction
The trained model predicts whether a patient is:
- Diabetic
- Non-Diabetic
